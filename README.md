# Full Stack open CI/CD

This repository is used for the CI/CD module of the Full Stack Open course.

## Live Application

The Pokedex application is deployed on Render:

[Open the live Pokedex application](https://fs-pokedex-kux0.onrender.com)

### Health Check

The health-check endpoint is available at:

`https://fs-pokedex-kux0.onrender.com/health`

## Commands

Start by running `npm install` inside the project folder.

- `npm start` to run the webpack development server
- `npm test` to run tests
- `npm run eslint` to run ESLint
- `npm run build` to make a production build
- `npm run start-prod` to run your production build
- `npm run test:e2e` to run end-to-end tests
